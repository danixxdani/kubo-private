KUBO — private room creation full flow

Everything discussed so far, merged into one flow. There are three entry points (two on profile, one on content), and all converge on the same gate logic — Private rooms are created instantly, Public requires applying to become a host.

Design note — both profile entry styles are included below: the 2-column "Public / Private" buttons nested inside "My Studio", and the original "+Create" button that keeps today's Public/Private toggle. Either way, only the Public path is gated into the host application — Private always goes straight to the simplified form.
Private — anyone can create instantly, no approval needed
Public — requires host approval; unapproved users are routed to the application flow

Entry point 1 — via "+Create" with the toggle kept

Instead of replacing "+Create" with two buttons, this version keeps today's single entry point and the Public/Private toggle at the top of the form exactly as it is. Private stays the default tab with the simplified form; only tapping the Public tab is gated — it routes to the same host application flow as Entry point 2 below, instead of opening a public broadcast form.
